# UI 2026.10.18.16 / FJGAC

- LocalDNS 的名称、Logo 与代理入口的名称、Logo、面板地址统一保存到服务器，其他浏览器或设备刷新后读取同一套设置。
- 首次连接时，服务器尚未设置的项目会从当前浏览器的旧偏好迁移；服务器已有设置时以服务器为准。
- 保存采用版本冲突检查、原子替换和上一份备份；保存失败保留当前显示并提示重试。
- 建议上传 256×256 的透明 PNG。上传文件上限为 2 MB，自动转换为最长边 256 像素的 PNG；服务器也校验上传结果。
- 存储文件默认位于 `/opt/localdns-proxy-config/data/interface.json`，独立于 UI 目录，UI 升级会保留。可通过服务配置 `interfaceFile` 指定路径。

需要独立配置服务 **1.3.0**。文件编辑和配置正文的浏览器存储策略保持原样，DNS 核心仍为 FJGAC。
