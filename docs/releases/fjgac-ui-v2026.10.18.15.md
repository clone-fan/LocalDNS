# UI 2026.10.18.15 / FJGAC

## 名称与 Logo

- 代理面板支持自定义名称、上传 Logo 或填写图片地址，顶栏保留仅图标入口。原来的固定核心名称与 Logo 选择已移除，已有面板地址保留。
- 在「外观 → 界面 → 名称与 Logo」设置 LocalDNS 的显示名称与图标，同步到顶栏、页面标题、侧栏状态与站点图标。
- 上传图片限制 2 MB，转换为适合图标的 PNG；名称与图片保存在当前站点的当前浏览器。提供恢复默认与保存失败反馈。

## 目录中的多份配置

- 配置编辑器支持单文件 / 目录两种读取方式，目录列表支持筛选、子目录导航、启动配置标识与文件切换。
- Mihomo 列出 YAML / JSON，sing-box 列出 JSON；每份文件作为完整配置单独执行核心校验。未保存的修改在切换文件前提示处理。
- 启动配置保存后按原有事务流程备份、重载，失败恢复。备用配置校验通过后单独备份和保存，不改变核心启动文件选择。
- 目录模式与选中文件保留到当前浏览器；配置正文不进入浏览器存储。手机通过可收起的文件列表切换配置。

需要同时升级独立配置服务到 **1.2.0**。DNS 核心仍为 FJGAC。
