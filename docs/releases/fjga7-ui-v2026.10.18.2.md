# LocalDNS FJGA7 / UI 2026.10.18.2

按已确认的 HTML 对照整合界面，保留现有双皮肤、导航、字体、壁纸、五个主路由和原有管理功能。

## 更新

- 首页同时显示域名、客户端与解析去向排行，名称和 IP 分行。缓存池与慢查询保留在下方。点击排行条目可筛选相关日志。
- 查询日志增加常用筛选、条件标签、显示列偏好、暂停刷新及当前页 JSON 导出。
- 单条请求详情改为路径摘要：请求来源、缓存记录、最终分流和返回应答可点开查看依据，保留原始日志。已有总耗时为 0 ms 时按接口原值显示。
- 在线分流规则按国内 / 海外用途分组，支持搜索及内容、来源、更新、高级详情。保留启停、更新、编辑、删除及 DAT 数据集选择；订阅表单草稿保留在当前浏览器会话。
- 上游按解析组展示请求份额、耗时、采纳率、错误与成功率，保留节点编辑、删除、启停和错误详情。
- 首页五列拓扑支持分支或节点锁定、清除、节点详情与相关分类日志。Esc 可取消锁定。
- 精简重复页名与说明，将标题、统计、提示和操作收进对应区域，沿用皮肤色彩与圆角参数。

## 数据边界

- 当前排行接口仅返回分类与请求数，没有各分类平均延迟时显示“—”；统计范围为当前审计保留记录，不声称是近一小时。
- 当前 FJGA7 日志未提供完整逐步执行事件，路径摘要仅组织已有字段。规则条目、具体上游、TTL 与阶段耗时未记录时保持未知，不从首页拓扑或查询类型推断。
- “解析去向”是最终分类，可包含缓存或本地应答。并发节点请求数与采纳率分开统计。
- 编译后的在线规则由订阅生成。详情显示已有数量、格式与文件信息；更改内容使用订阅编辑或原有本地名单编辑器。

本次包只更新 UI，继续使用 FJGA7 内核。
