# FJGAC / UI 2026.10.19.5

将本机验证的 2026.10.19.1–.5 界面调整合并为正式版。DNS 核心继续使用 FJGAC，配套服务继续使用 1.5.0。

## 本次更新

- 查询处理结果使用中文名称，默认显示前五类和“其他”，可展开全部分类并筛选对应日志。
- 明确统计口径：结果占比来自审计保留日志中的最终处理结果；缓存命中不展开原本的国内 / 国外去向。
- 慢查询默认显示十条，可选择 5 / 10 / 20 条，包含域名、类型、客户端和最大耗时；点击域名追溯日志。
- 四个缓存池补充查询数、命中数与当前条目；桌面缓存区与慢查询卡上下沿对齐，慢查询在卡内滚动。
- 三组 TOP 排行外框对齐，手机排行保持紧凑同行；慢查询表头去掉整条背景，只保留列名与分隔线。
- 外观面板采用“主题背景 / 材质与布局 / 品牌与字体”三栏胶囊，滑块与数值、URL 与应用按钮同行，保留既有设置。
- 统一同级板块间距、卡片内边距、页头与手机触摸区域；改善羊皮纸深色文字对比度、缓存字段折行及长路径显示。
- 修复从手机宽度切回桌面或切换皮肤时，底部卡片保留旧高度造成的大块留白。
- 手机查询日志默认 25 条，三行紧凑记录，常用设置默认折叠，增加顶部分页。
- 顶栏增加版本与更新入口，每六小时自动读取 GitHub 最新正式版，支持手动检查和失败重试。

## 下载与升级

| 文件 | 用途 |
|---|---|
| `LocalDNS_UI_2026.10.19.5_Update.zip` | 已安装环境更新界面 |
| `LocalDNS_FJGAC_UI_2026.10.19.5_Full.zip` | 新安装；核心及默认配置、规则沿用上一正式版 |
| `LocalDNS_ProxyConfig_UI_2026.10.19.5_Service.zip` | 配套服务 1.5.0，已有该服务无需重复升级 |
| `SHA256SUMS.txt` | 三个安装包的 SHA-256 校验值 |

UI 升级通常无需重启 DNS。将升级包解压后运行 `sh install-ui.sh /opt/localdns`，按实际安装路径调整；随后刷新浏览器。

完整包以 GitHub 已发布并核验 SHA-256 的 2026.10.18.19 完整包为基础，不从运行中的设备导入配置、规则或缓存。作者署名和第三方许可继续保留。

验证范围与限制见 [验证记录](../validation/ui-2026.10.19.5.md)。
