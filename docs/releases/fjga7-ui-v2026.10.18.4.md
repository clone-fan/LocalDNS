# LocalDNS FJGA7 / UI 2026.10.18.4

## 更新

- 在线分流规则支持「分组卡片 / 表格列表」切换，恢复原九列列表，并保留详情、更新、编辑、启停和删除入口。
- 广告订阅、DNS 上游、查询日志、缓存管理和功能开关统一支持「卡片 / 列表」切换。
- 各板块独立保存排列偏好，并按 API 地址隔离；切换只调整本地显示，不重新请求数据或重建业务页面。搜索、筛选、分页、未提交输入和已保存的订阅草稿保留。
- 桌面默认排列沿用当前界面：在线规则、缓存和功能开关为卡片，广告订阅、上游和日志为列表；手机尚未保存偏好时使用卡片。
- 手机尊重用户选择的排列：卡片适配窄屏，宽表在自身容器内横向滚动。保留双皮肤、横向 / 纵向导航、字体、壁纸和现有操作。

## 下载

- `LocalDNS_FJGA7_UI_2026.10.18.4_Full.zip`：FJGA7 三种架构预编译程序、已清理的默认配置与本版 UI。
- `LocalDNS_UI_2026.10.18.4_Update.zip`：仅更新界面。
- `SHA256SUMS.txt`：两个发行包的 SHA-256 校验值。
