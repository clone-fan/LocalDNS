# LocalDNS FJGA7 / UI 2026.10.18.3

整合本日 2026.10.18.1、2026.10.18.2 的更新及排行顺序修复。

## 更新

- 内核升级为用户提供的 FJGA7，提供 amd64-v1、amd64-v3、arm64 三种程序；完整包默认 amd64-v3。没有上游内核变更清单，不推测内部修复。
- 功能开关恢复上下分区；外观面板支持垂直、折叠与水平导航。保留人文羊皮纸 / 流光毛玻璃双皮肤、字体、壁纸与五个主路由。
- 首页同时展示域名、客户端和解析去向排行；修复排行遗漏显示顺序而出现在首排的问题。服务状态与核心指标居前，排行位于趋势图、解析拓扑之后，缓存池与慢查询之前。
- 查询日志新增常用筛选、条件标签、显示列偏好、暂停刷新和当前页 JSON 导出。
- 单条请求详情采用可查看依据的 DNS 解析路径摘要，保留原始日志。
- 在线分流规则增加用途分组、搜索、详情与会话内草稿；上游按解析组展示请求份额、耗时、采纳率、错误和成功率。
- 拓扑支持分支 / 节点锁定、详情与相关分类日志；精简重复文字，标题、统计、提示和操作归入对应区域。
- 更新静态资源版本号，使刷新后的浏览器加载最新排列。

## 下载与安装

- `LocalDNS_FJGA7_UI_2026.10.18.3_Full.zip`：三种架构的 FJGA7 预编译程序、已清理的默认配置与当前 UI。
- `LocalDNS_UI_2026.10.18.3_Update.zip`：仅更新 UI，不升级内核。
- `SHA256SUMS.txt`：两个包的 SHA-256 校验值。

已有部署保留配置、规则及数据。UI 升级包先校验、备份再替换界面；内核升级从完整包选择对应架构程序，按 INSTALL.md 备份和验证，不用完整目录覆盖已有安装。

## 数据与验证范围

- 当前内核未提供完整逐步执行事件。路径摘要只组织该请求已有字段，未记录的规则、具体上游、TTL 和阶段耗时保持未知。
- 排行范围为当前审计保留记录；接口未提供的平均延迟显示“—”。最终解析去向与并发上游采纳率分别统计。
- amd64-v3 内核已在现有 Alpine 环境验证；amd64-v1、arm64 只核验 ELF 架构和包完整性，未运行验证。
- UI 部署已核对文件 SHA-256、配置保留、DNS TCP / UDP 与现有 API；排行顺序在只读预览及线上页面确认。本次 UI 部署未重启 DNS 服务。
