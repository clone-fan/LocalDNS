# LocalDNS UI 2026.10.18.9 / FJGAC

历史说明：本版的图库管理已按用户要求在 [UI 2026.10.18.11](fjgac-ui-v2026.10.18.11.md) 移除，当前仅保留单张壁纸设置。以下记录保留本版当时的功能与验证结果。

本次按“只改 UI”的范围补齐浏览器壁纸库。DNS 内核和服务器配置保持原样。

## 壁纸管理

- 外观 → 流光毛玻璃 → 壁纸 → 管理壁纸，支持本地图片、在线图片 URL、预览、应用、重命名和删除。
- “恢复默认”只切换背景，不清空图库。删除当前壁纸时需确认“恢复默认并删除”。在线图片删除只移除保存的地址。
- 单张新图片上限 20 MB，图库最多 32 张、本地文件总量 128 MB；已有的大图继续保留。浏览器实际可用空间较小时，会报告保存失败并保留原数据。
- 旧壁纸自动读取为图库条目；第一次保存操作在同一个 IndexedDB 事务中写入图库并移除旧记录，避免删除图片后仍残留旧版引用。旧版本 UI 无法读取新图库，回退 UI 时可能显示默认背景，但新图库仍保留。
- IndexedDB 是图库唯一可写来源，保存、改名和删除使用事务并检查版本，避免其他标签页把已删除的壁纸写回。已有 IndexedDB 图库优先于旧 localStorage 后备数据，只有库为空时才读取旧数据并等待事务迁移。
- IndexedDB 暂不可用时进入只读模式，尽可能读取旧 localStorage 数据供预览；添加、应用、重命名、删除及恢复默认均被拒绝，不向 localStorage 另写图库，避免多个标签页产生分叉或互相覆盖。允许站点存储并刷新图库后可重试。

## 存储范围

当前图片和图库仅保存在当前站点、当前浏览器。清除站点数据会清空壁纸库。服务端选项明确显示暂不可用，不发送图片到服务器，也不承诺跨设备同步。

用户确认没有内核源码并要求只考虑 UI；本次不增加资源服务、不修改 DNS 内核。服务器共享图库仍保留为后续方案，需有可用的存储接口后再启用。

## 验证

`node --test tools/test_wallpaper_store.cjs` 的 7 项测试通过，覆盖删除与恢复默认的区别、文件/库容量限制、非法名称/URL、持久化、并发版本冲突、事务失败回滚、旧图迁移、两个降级标签页均拒绝写入，以及已有 IndexedDB 暂不可读时不另建图库。

测试依赖安装到忽略目录：`npm install --prefix deployment/tools/wallpaper-test-deps fake-indexeddb@6.2.4`。
