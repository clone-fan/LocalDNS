## sing-box 多文件分片

- 支持 `-C` 配置目录及附加 `-c` 文件；可从经过核验的运行进程读取启动参数，或由服务配置声明。
- 编辑一份运行分片时，复制整套输入到隔离目录，保留文件路径的排序关系，调用 sing-box 自身的 merge / check。
- 保存前核对整个集合的版本，检查常见跨文件出口引用，按文件备份并原子替换；随后重载整套配置，失败恢复原分片。
- 界面标记运行分片、显示集合数量，支持含注释的 JSON 分片；备用完整配置继续单独校验和保存。
- Alpine 兼容加载器通过程序路径及可执行映射的 inode 核验进程。sing-box 的重载确认仍表述为“已发送重载且核心在线”。

配套配置服务为 **1.4.0**。真实 Linux sing-box **1.14.3** 已在隔离配置中验证合并、跨文件错误拦截、保存 / SIGHUP 重载和失败恢复；现有 Mihomo 与 DNS 配置保持。
