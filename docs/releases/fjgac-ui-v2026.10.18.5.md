# LocalDNS FJGAC / UI 2026.10.18.5

## 更新

- 内核更新为 FJGAC。完整包仅从用户提供的原版 ZIP 提取 amd64-v1、amd64-v3、arm64 三种架构程序，默认配置和规则沿用上一正式发行包；保留当前双皮肤、导航和卡片 / 列表选择。
- 修复首页域名、客户端和解析去向排行的平均延时始终显示“—”。排行接口只有名称和请求数时，按各项请求日志计算，包含缓存和本地应答的真实耗时。
- 每项最多读取最近 1,000 条日志，超出时标注“近 1,000 条”；有真实 0 ms 时照常显示，无有效样本时显示“暂无样本”。结果缓存 60 秒，最多 4 个并发请求，可见条目按需加载；读取失败可重试。
- “更多”排行抽屉同样支持延时计算。请求数与延时的统计口径在页面中明确说明。

## 验证范围

- 在现有 amd64-v3 设备的独立回环端口复制环境中检查 82 项接口与操作：日志和筛选、名单保存、客户端别名、上游增删改、五类在线分流订阅下载与增删改、广告订阅更新、8 个开关、缓存、审计和刷新任务。写入测试不作用于正式配置。
- 备份后升级内核，检查真实运行版本、TCP / UDP 53 查询和现有配置 / 手工规则完整性；随后更新 UI 并核对文件。
- ARM64 与 amd64-v1 核验 ELF 类型、SHA-256 和发行包内容，未宣称完成其他架构运行测试。
