# LocalDNS FJGAC / UI 2026.10.18.7

## 修复与调整

- 拓扑改为单层毛玻璃画布，内部节点使用统一的半透明底色，移除叠加模糊与固定渐变；模糊度和遮盖度继续使用全局外观设置。保留深浅玻璃及羊皮纸皮肤。
- 修复在线规则编辑、开关保存后丢失已识别格式的问题：来源不变时保留识别元数据，来源变化时重新识别。
- 修复更新接口返回来源对象却被提示为“规则未变化”的问题；批量更新按接口实际成功数量汇总。
- 对保存后仍待识别的来源执行更新检查，多数据集 DAT 可继续选择数据集，不将待转换状态提示为成功。
- 吞吐量展示最近采样 QPS、区间均值、峰值与请求数，移除混杂的 CPU、内存和累计请求图例。曲线随容器宽度绘制，横轴显示实际已有采样时段。
- QPS 使用内核累计请求计数的增量；按有效时间计算均值，重启或计数重置重新建立基线，断采不补零、不跨缺口连线。

## 内核核对

本次 `LocalDNS_FJGAC.zip` 的 AMD64-V1、AMD64-V3、ARM64 程序与上一版发行包一致，线上 AMD64-V3 程序也与 ZIP 完全一致。本版完整包再次从该 ZIP 导入三架构内核，版本继续为 FJGAC。

## 验证范围

- 隔离副本验证 TXT、YAML、Sing-box JSON、Hosts、DNSMasq 转为 SRS；HTML 错误页面被拒绝。
- 隔离副本复现识别元数据丢失，验证保留字段后不再丢失；多数据集 DAT 在选择后可转换。
- 25 个现有在线来源均已识别，其缓存文件具有 SRS 文件头。
- 桌面与 390px 手机宽度检查，深浅玻璃、羊皮纸、全局外观滑块与控制台错误检查。
- 本版针对上述问题验证，未重新执行所有后端功能，也未在实体手机上测试。

## 下载与使用

- `LocalDNS_FJGAC_UI_2026.10.18.7_Full.zip`：FJGAC 三架构程序、干净默认配置与本版界面。
- `LocalDNS_UI_2026.10.18.7_Update.zip`：仅界面更新，保留现有配置与内核。
- `SHA256SUMS.txt`：安装包校验值。

升级后刷新页面，必要时使用 Ctrl+F5。吞吐量需要至少两次有效采样；它记录当前浏览器会话采集的数据，不提供服务器历史回溯。
