## 本版变化

- **DNS 解析路径采用 UI 2026.10.16.1 的五列布局**：22px 列间距、并排节点信息和居中连线，不含 .2 版公式栏、预设工具条和出口矩阵。
- 在该布局上整合可关闭的路径流光、玻璃细节、圆角和版本标签设置；保留鼠标 / 键盘节点追踪、减少动画偏好与切页清理。流光是路径示意，不是逐请求实时追踪。
- 支持浏览器本地字体上传，分别用于标题、数字、正文；保留原有字体偏好和技术内容等宽字体。字体不发送到服务器，存储失败时保留原设置。
- 增强排行弹窗、遮罩关闭、快捷搜索、日志复制与键盘操作。
- 修复数字滚动覆盖单位结构的问题，支持数字排版自恢复，同时保留减少动画与切页安全保护。
- 不修改 DNS 解析逻辑、现有配置或规则。完整包后端与默认配置沿用已发布、SHA-256 校验通过的 FJG4O 完整包。

## 下载与更新

| 附件 | 用途 |
|---|---|
| `LocalDNS_FJG4O_UI_2026.10.16.3_Full.zip` | 新安装，含 FJG4O 程序、默认配置、规则和 UI |
| `LocalDNS_UI_2026.10.16.3_Update.zip` | 已安装环境只更新 UI |
| `SHA256SUMS.txt` | 两个 ZIP 的 SHA-256 校验值 |

已有服务请解压 **Update** 包，在解压目录执行 `sh install-ui.sh /opt/localdns`。脚本先校验、备份再切换 UI，不替换后端、配置和规则，通常无需重启。不要用完整包覆盖现有安装目录。

FJG4O 提供 amd64-v1、amd64-v3 和 arm64；完整包默认使用 amd64-v3，未附 ARMv7。架构选择和回退步骤见 [安装说明](https://github.com/yyhoworks/LocalDNS/blob/ui-v2026.10.16.3/INSTALL.md)。

- JavaScript 语法、ZIP CRC、逐文件 SHA-256、执行权限及基础包后端 / 配置 / 规则不变性检查。

未重新构建或逐架构运行 Rust 核心，未声称覆盖真实手机硬件或其他浏览器。README 图集仍标注为 .2 版历史截图；本次不发布含真实设备信息的测试截图。
