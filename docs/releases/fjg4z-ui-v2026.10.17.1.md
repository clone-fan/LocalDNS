# LocalDNS FJG4Z / UI 2026.10.17.1

本次发布修复双皮肤主题状态，并调整顶栏快捷入口位置。后端保持 FJG4Z，DNS 服务、配置和规则不变。

## 更新内容

- 修复「流光毛玻璃」深色 / 浅色主题无法切换的问题；每套皮肤继续独立保存自己的主题偏好。
- 将「流光」开关放到「外观」旁边，桌面显示文字，窄屏保留图标并适配触控尺寸。
- 统一主题切换的点击与键盘事件，路由刷新后入口仍可用。
- 保留壁纸 IndexedDB、毛玻璃模糊 / 遮盖度 / 背景暗化、拓扑流光与粒子开关、DNS 五列解析路径、字体、规则草稿及原有业务页面。
- 资源查询版本更新为 `20261017-1`，用于刷新浏览器缓存。
