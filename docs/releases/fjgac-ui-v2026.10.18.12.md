# LocalDNS UI 2026.10.18.12 · 本地预览

## 代理面板入口

- 顶栏只显示 Mihomo 或 sing-box 官方 Logo，点击后在新标签页打开面板。
- Logo 右侧箭头打开类型与地址设置；默认地址为 `http://192.168.8.7:9090/ui`。
- 支持自定义 HTTP(S) 地址；设置保存在当前浏览器，不向 LocalDNS 后端写入配置。
- 系统管理提供面板设置入口。取消或保存失败时保留原设置；支持 Escape、焦点恢复与点击外部关闭。
- 入口宽度为桌面 64px、手机 62px；使用现有外观变量，兼容双皮肤和水平 / 垂直导航。

此版先供本地设备预览，后端仍为 FJGAC。
