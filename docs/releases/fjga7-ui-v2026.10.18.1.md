# LocalDNS FJGA7 / UI 2026.10.18.1

## 更新内容

- 功能开关恢复 PR #1 合并前的上下分区：标题和说明位于上方，状态在底部左侧，开关在底部右侧；桌面与手机沿用同一结构。
- 参考用户本地 OxiDNS 项目的导航布局，新增「外观 → 导航布局 → 垂直 / 水平」。垂直侧栏可折叠为图标，水平导航居中于顶栏；手机继续使用原有底部导航。
- 导航偏好独立保存；切换布局时不重新创建业务页面，不丢弃未保存的规则草稿。拓扑连线与规则编辑区随可用空间重新计算。
- 保留人文羊皮纸 / 流光毛玻璃双皮肤、独立主题、壁纸、字体、流光开关、五阶段 DNS 解析路径及原作者署名。
- 内核来自用户提供的 `LocalDNS_FJGA7.zip`，只引入 amd64-v1、amd64-v3、arm64 三种程序；完整包默认 amd64-v3。
- 打包工具支持上游 ZIP 的额外目录层级，检查路径、重复条目、ELF 架构和默认程序一致性；配置和规则沿用已发布的 FJG4Z / UI 2026.10.16.3 完整包。
- UI 安装脚本从包内版本信息生成备份名称和安装提示。
