# LocalDNS UI 2026.10.18.11 / FJGAC

## 相对上一正式版 .7 的更新

- 客户端管理展示全部已保存别名和最近最多 200 个查询来源，支持搜索、IPv4/IPv6 新增、改名和移除；点击保存后写入服务器。
- 保存前读取服务器最新别名表，保留无关条目的修改，发现同一别名冲突时停止保存。后端没有原子版本检查，完全同时提交仍可能互相覆盖。
- 客户端拓扑只展示有实际查询的来源，取消旧别名和虚构终端的补位；无记录时显示明确的空状态。
- 按用户要求移除整个浏览器壁纸图库功能，包括管理入口、图片列表、容量统计、刷新、重命名、删除，以及保存范围选项。
- 保留单张本地图片、在线图片 URL、背景预设与恢复默认；每次选择替换当前壁纸。
- 旧图库当前选中的图片或预设自动兼容；读取为单张设置后，恢复默认和后续替换会持久保存，不会重新显示旧图。
- 壁纸仍只保存在当前浏览器。内核保持 FJGAC。

此前取消的 .10 独立同步原型继续归档，不参与打包。

## 下载与使用

- `LocalDNS_FJGAC_UI_2026.10.18.11_Full.zip`：FJGAC 三架构程序、已清理的默认配置与本版界面。
- `LocalDNS_UI_2026.10.18.11_Update.zip`：仅界面更新，保留现有配置与内核。
- `SHA256SUMS.txt`：两个安装包的 SHA-256 校验值。

已安装环境优先使用 UI 升级包，按安装说明执行后刷新浏览器，必要时使用 Ctrl+F5。完整包沿用已发布 .7 的 FJGAC 内核、默认配置和规则；没有新的内核升级。

## 验证范围

客户端管理与壁纸兼容的 10 项测试通过；壁纸设置已检查桌面和 390px 手机宽度，验证在线 URL 保存、刷新恢复和恢复默认持久化。两个发行包均检查 ZIP 完整性、包内清单、源文件一致性，以及内核、配置和规则保持一致。未重新执行全部后端功能或实体手机测试。
