# UI 2026.10.18.19 / FJGAC

修复 .18 清单工作台中编辑后无法取消的问题。此前关闭逻辑一直返回提示，没有真正放弃修改的分支；现在显示「继续编辑 / 放弃修改」，不再连续堆积提示。

## 修复内容

- 备注、分组、规则类型与新增项注释都参与未保存判断。识别前缀只改变编辑框，取消不会改写原规则；`#` 开头的规则正确保持停用。
- 编辑框中的 Ctrl+S 将当前内容应用到名单草稿；名单页「保存」才写入服务器。中文输入法确认文字时不会提前提交。
- IP、CIDR 和重定向新增条目保留原文格式；批量粘贴去除现有名单和同次粘贴中的重复规则；面板删除只确认一次。
- 切换页面、名单、标签与刷新前保护尚未应用的字段；隐藏面板不再抢焦点，模态背景不可操作，离开页面清理浮层。
- 两套皮肤的编辑字段独立滚动，短屏仍能看到关闭与应用按钮；手机输入和触摸控件调整尺寸。

## 安装与验证

已安装 .18 的用户升级 UI 即可，配置管理服务继续使用 **1.5.0**。完整包与 Service 包仍一并提供，便于新安装。原有服务器备份、配置文件、名单和共享设置继续保留。

已运行规则编辑器与工作台隔离回归，覆盖关闭、草稿、分组、粘贴、拖动、备份失败、保存失败、并发修改、恢复为草稿、两套皮肤与桌面 / 小屏布局；另回归共享标识、配置目录、sing-box 分片及七天流量历史。静态检查使用 Impeccable audit / harden。详情与验证限制见 [审查记录](../validation/rules-editor-2026.10.18.19.md)。

完整包从已验证的干净 .14 模板生成，不含部署设备的私人配置或名单。Linux arm64 构建及归档验证不代表在 arm64 设备上实际运行通过。
