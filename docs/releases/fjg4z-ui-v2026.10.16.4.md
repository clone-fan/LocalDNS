# LocalDNS FJG4Z / UI 2026.10.16.4

本次正式发布 **UI 2026.10.16.4（后端 FJG4Z）**，新增 **「人文羊皮纸 · Claude」** 与 **「流光毛玻璃 · 原版」** 双皮肤体系及无刷新一键切换，完整保留 FJG4Z 内核、五列 DNS 解析路径垂直居中布局与所有贡献者署名。

## 更新亮点

- **双皮肤体系与双入口无刷新切换**：
  - **顶栏快捷胶囊**：在右上角状态栏旁新增 `[人文羊皮纸 | 流光毛玻璃]` 切换器，一键即时切换整站视觉体系。
  - **外观面板双皮肤卡片**：「外观」弹窗顶部新增可视化皮肤卡片，并根据当前所选皮肤智能切换专属调校项。
- **人文羊皮纸（Claude 风格，`html[data-skin="claude"]`）**：
  - 采用温润羊皮纸底色（`#F5F2EA` / `#FCFBF8`）、深炭墨色（`#191816`）与赤陶主色（`#C96442` / `#D97757`）、鼠尾草绿（`#2D6A4F`）、琥珀赭（`#B45309`）书卷配色，搭配 SVG 宣纸纤维肌理层与 1px 温润墨线描边。
  - 提供 **经典羊皮纸 / 暖陶宣纸 / 鼠尾草笺 / 纯粹原白 / 夜读黑曜（深色模式）** 5 款预设色调，以及 **纸张肌理浓度（0–60%）** 与 **卡片温润层次（0–100%）** 滑杆。
- **流光毛玻璃（原版风格，`html[data-skin="glass"]`）**：
  - 100% 保留原版深空暖金、极光深海等 5 组光影预设、本地壁纸 IndexedDB 存储与毛玻璃模糊度 / 面板遮盖度 / 背景暗化遮罩调节。
- **五列 DNS 解析路径与独立偏好持久化**：
  - `DNS 解析路径` 保持正式版五列垂直居中对齐布局，节点图标、贝塞尔连线与分流占比环形图色彩随当前皮肤自动适配。
  - 两套皮肤各自独立保存深浅色主题、预设与滑杆参数（`localdns-skin-v1`）。
