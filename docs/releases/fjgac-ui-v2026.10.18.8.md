# LocalDNS 客户端管理修复 / UI 2026.10.18.8

后端继续使用 FJGAC，本次只更新 UI。

- 点击运行概览的“客户端数”，或查询日志的“客户端管理”，管理所有已保存别名和最近最多 200 个查询来源。
- 支持搜索、IPv4/IPv6 新增、改名和移除。更改先保留在当前窗口，点击“保存”后写入服务器，其他设备刷新可见。
- 保存前读取最新别名表，保留其他设备对无关条目的修改；检测到所编辑条目变化时停止保存。现有后端未提供原子版本检查，不能保证完全同时写入的两个请求不会互相覆盖。
- 拓扑只展示实际有查询的来源；没有查询的保存别名不会被补成零请求客户端。空记录显示明确的空状态。
- 删除别名不删除查询记录，不改变设备准入或 DNS 分流规则。

壁纸仍按原方式保存在当前浏览器。服务端共享库及其删除流程见 [多端壁纸方案](../WALLPAPER-SYNC-PLAN.md)，尚未实装。
