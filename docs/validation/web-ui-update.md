# 网页 UI 升级验证

日期：2026-10-19。发行版本为 UI **2026.10.19.9** / FJGAC；构建产物位于忽略目录 `dist/fjgac-ui-v2026.10.19.9/`，不覆盖既有 `.8` 正式发行包。

## 实现范围

- 扩展现有版本弹窗：连接执行端、口令授权、指定版本升级、任务进度、失败重试、完成后手动刷新及恢复上一版。
- 可选 Python 执行端提供 `/upgrade/ui`，独立于 DNS 核心，默认管理端口 9100。首次安装需要 root；没有修改预编译 Rust 核心。
- 复用安装器的发行包 / 文件清单校验、配置保留、备份和健康检查回退。增加共用安装锁、切换事务恢复和上一构建静态资源保留。
- 安装器 1.2.0 增加 `--with-ui-updater`；新旧发行包有明确能力检查。完整包和 UI 升级包携带执行端安装工具。

## 验证边界

开发验证环境为 Windows、Python 3.13、Node 24 和 Edge。另在用户指定的 Linux x86-64 / OpenRC / Python 3.12.15 主机完成全部 42 项 Python 测试，并通过真实 GitHub 正式包下载、口令授权、文件替换、版本与管理接口检查（隔离目录）。随后部署 UI 2026.10.19.9 与更新执行端，确认 OpenRC 运行与开机启动、TCP / UDP 53 解析、原 DNS 进程和受保护配置不变。尚未完成 systemd、ARM64 实机或其他浏览器认证。

执行端默认以 root 服务运行，需要写入固定安装目录与安装锁；不执行网页传入的命令、地址或路径，也不执行升级包中的安装脚本。首次安装和更新执行端本身仍需执行安装命令，之后的 UI 升级由网页发起。安装与 HTTPS 代理说明见 [网页升级指南](../WEB_UPDATE.md)。
