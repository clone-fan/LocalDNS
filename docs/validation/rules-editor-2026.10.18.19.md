# 名单编辑器审查与修复

范围：.18 新合入的名单工作台、相关草稿 / 路由 / 保存流程，以及受影响页面的回归。依据 Impeccable audit / harden、源代码审查、Edge 隔离夹具和桌面 / 小屏截图。所有模拟保存均由夹具接收。

## 已确认并修复的问题

| 级别 | 问题与影响 | 修复与验证 |
|---|---|---|
| P1 | 脏编辑框的关闭分支只提示并返回，用户无法放弃；连续五次出现五条提示 | 显式继续 / 放弃，连续点击仅显示一份确认；类型、备注、分组、新增注释均覆盖 |
| P1 | 前缀识别在应用前改变行类型，取消仍影响后续写回；停用前缀丢失 | 编辑状态独立，提交才写模型；取消后原文启停仍保持 raw，新增停用行正确写回 |
| P1 | 面板内 Ctrl+S 保存了未包含当前字段的旧名单 | 面板内应用草稿，页面保存写服务器；验证应用后 DNS 写入次数仍为零 |
| P1 | 隐藏面板进入焦点顺序，模态背景可操作 | 隐藏 inert、背景隔离、焦点循环、关闭归还焦点与取消延迟聚焦；对应 WCAG 2.1.1 / 2.4.3 |
| P2 | 备注 / 分组等部分字段漏判脏，切页或刷新会丢失尚未应用的输入 | 字段快照、canLeave、beforeunload；覆盖页面 / 名单 / 标签 / 刷新 |
| P2 | IP / CIDR / 重定向新增误加域名前缀，格式错误 | 按名单创建 raw 行，空值及重复项被拒绝 |
| P2 | 删除连续确认两次，粘贴未去重同批规则，浮层缺少原生焦点管理 | 单次删除确认、Set 去重、原生 dialog、页面清理与 Escape 测试 |
| P2 | 短屏长内容挤出操作按钮，输入法 Enter 可能提前提交 | 字段区滚动、固定操作区、触摸尺寸、IME 事件保护；两套皮肤 390×568 验证 |

## 结果

关键操作流程通过隔离浏览器验证；工作台备份优先、失败保留草稿、跨名单异步保存、外部修改检测及恢复为草稿继续通过。名称 / Logo 共享、Mihomo 目录配置、sing-box 分片集合校验与保存、五个历史时间范围及流量读取失败恢复也通过回归。1000 行名单可渲染和搜索；耗时是本机观测值，不作为所有设备的性能承诺。

| 审查维度 | 修复前 / 4 | 修复后 / 4 | 依据与限制 |
|---|---|---|---|
| 无障碍 | 2 | 3 | 已核验键盘、焦点与背景隔离；未做读屏器全量认证 |
| 性能 | 3 | 3 | 空闲 DOM 无循环重绘，1000 行渲染 / 搜索通过；未测更大名单 |
| 响应布局 | 3 | 4 | 两套皮肤、两种导航、桌面与 390×568 短屏；真实手机键盘未验证 |
| 主题 | 3 | 3 | 使用现有主题令牌；保留用户已选皮肤和原有视觉语言 |
| 实现完整性 | 2 | 4 | 关闭、撤销、失败、草稿、保存边界与浮层生命周期均有回归证据 |
| 合计 | 13 | 17 | 分数是本次范围内的审查结论，不代表全产品认证 |

Impeccable 静态 detector 扫描修改后的 `rules-view.js` / `rules-view.css`，返回空发现集。未用检测器分数替代浏览器检查，也未因此更换原有皮肤。验证脚本：`tools/verify_rules_editor.cjs`、`tools/verify_rules_workbench.cjs`、`tools/verify_identity_directory.cjs`、`tools/verify_server_traffic_fragments.cjs`。

DNS 与代理核心并非本次修改范围；真实环境只读检查并核对部署前后配置 / 名单哈希，保存与故障分支使用独立夹具。Edge 桌面模拟小屏不等同于物理触屏、iOS、读屏器或全浏览器覆盖。
