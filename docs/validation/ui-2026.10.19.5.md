# UI 2026.10.19.5 验证记录

本版合并本机已部署验证的 UI 调整，正式发布前更新渠道与版本元数据。

发布前的自适应回归发现并修复了自动刷新临时锁定页面最小高度时，网格行被拉伸而产生大块留白的问题；网格按内容从顶部排列，卡片采用自然高度，桌面慢查询仍由缓存区内容确定高度并内部滚动。通过固定较大页面最小高度复现并核对修复结果，避免只依赖刷新时序。

## 已验证

- Edge / Chromium，桌面 1440px 与手机 390px，双皮肤的概览、日志、DNS 管理、规则、系统管理、代理配置共 24 组页面检查通过，无整页横向溢出和页面脚本异常。
- 概览对齐覆盖玻璃深色、羊皮纸浅色、羊皮纸深色，2580、1440、1251、1100、390、320px 共 18 组，桌面三卡等高及底部两卡对齐、20 条慢查询滚动通过。
- 最终表头透明样式在三种皮肤 / 明暗组合的桌面和手机共 6 组检查通过，列名颜色与 TOP 表头一致，未叠加独立背景或模糊。
- 羊皮纸默认深色背景的缓存文字样本对比度为 6.54:1–8.03:1；11px 辅助文字样本为 6.83:1–6.99:1。
- 已部署版本逐项核对 75 个 UI 文件；DNS 进程、受保护配置及手工规则保持不变，TCP / UDP DNS 解析正常。

## 可复现命令

正式版发布前回归：概览 / 更新检查的 12 组布局与网络状态场景、外观设置的 10 组布局与持久化场景均通过。自动刷新临时锁定页面高度的复现用例通过；核心包结构测试 8 项、查询结果聚合与排行延时测试通过。完整包 85 项核心 / 配置 / 规则文件与基础包逐字节相同，服务包除版本元数据与清单外的载荷相同；包内清单、CRC、最终 SHA-256 及暂存 UI 内容一致性核对通过。

```sh
node tools/test_overview_insights.cjs
node tools/test_rank_latency.cjs
node tools/verify_overview_insights.cjs
node tools/verify_appearance_layout.cjs
python tools/test_package_ui.py
```

浏览器验证默认读取本地测试后端；可通过脚本支持的环境变量指定实际部署地址。业务写入被阻止或使用隔离夹具，截图留在忽略的 `dist/`。

发布包使用上一正式版的完整 ZIP 作为核心、默认配置和规则来源；核对 GitHub 附件摘要、包内清单与最终附件 SHA-256。

## 限制

手机采用模拟视口，未做实体触摸或屏幕阅读器认证。对比度结果仅代表默认背景样本。DNS 运行检查针对已有 amd64-v3 设备，未逐架构重新执行 FJGAC 内核；配套服务功能沿用 1.5.0。
